# Mycelium Ops

One app to run a company with many sites: people, rosters, approvals, the calendar, physical and cyber security, documents and audit evidence. Everyone uses the same app, and each person sees only what their job needs.

**Prototype 1** (tag `prototype-1`, 6 Nov 2026): a clickable demo on a made-up manufacturer, Brolga Industries, for a design partner to review. Everything in it is fictional. See [what's in it and how to run it](demo/README.md), the [roadmap](docs/roadmap.md) and the [design](DESIGN.md).

Part of the Mycelium family with [Mycelium Monitor](https://github.com/tristan-pofandt/mycelium-monitor) (watching apps) and Mycelium Commerce (running a shop). All three share one look; this repo holds its reference copy.
